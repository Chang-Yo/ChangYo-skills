# 设计系统的选择

首先判断该项目是否已有部分前端代码：

- 如果有，检查是否存在已经设计好的一套设计系统
  - 如果存在，直接使用即可，并且可以完善不完整的设计系统
  - 如果不存在，除非代码都十分明显地遵循一套设计规范，尽量先阅读前端文件来提取一套设计系统
- 如果没有，意味着这是一个全新的项目，直接跳转到对应小节来了解设计系统的创建

**设计系统的规范最好放在单独的文件或文件夹中。**
